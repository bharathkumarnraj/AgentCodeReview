# AgentCodeReview
AgentCodeReview is a multi-agent AI framework for explainable code review and automated bug repair using Large Language Models (LLMs). The system integrates specialized AI agents for review, security analysis, performance optimization, documentation assessment, and automated repair. It provides quality scoring, HTML/PDF reporting, and an interactive Streamlit interface.
